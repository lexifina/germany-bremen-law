1. | für Haushaltsvorstände und Alleinstehende | 
 |  | 347 Euro
2. | für sonstige Haushaltsangehörige | 
 | a) | bis zur Vollendung des 14. Lebensjahres
 |  | 208 Euro
 | b) | ab Vollendung des 14. Lebensjahres

3. | für zusammenlebende Ehegatten oder Lebenspartner | 
 |  | 312 Euro
